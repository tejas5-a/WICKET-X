<div align="center">THE GAME. THE NUMBERS. THE EXPERIENCE.

WicketX is being built to bring cricket scoring, match management, player performance, and tournament experiences together in one modern Android application.

</div>◈ 01 — THE VISION

Cricket deserves more than a basic scoreboard.

WicketX aims to deliver a unified experience for match organizers, scorers, players, and cricket fans.

From recording every delivery to following tournament standings, the goal is to make cricket management intuitive, reliable, and beautiful.

◈ 10 — SECURITY

Security is part of the development process.

- Keep private credentials outside source control.
- Never include Supabase service-role keys in the APK.
- Use appropriate database access policies.
- Validate sensitive operations on the server.
- Report security issues privately.
